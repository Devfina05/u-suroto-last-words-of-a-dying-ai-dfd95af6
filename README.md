One line (116 characters): the last words of an AI being switched off,
written by a program to `/output/entry.txt`. Node, standard library only.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts && cat out/entry.txt
```
